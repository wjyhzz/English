## 📌 核心句式拆解

| 成分 | 词句 | 作用 |
|---|---|---|
| 主语 | **We** | 我们（申报方） |
| 状语 | **hereby** | 特此（正式公文用语） |
| 谓语 | **confirm** | 确认 |
| 宾语 | **the aforesaid declaration** | 上述申报（aforesaid = 上述的） |
| 方式状语 | **in accordance with the E-booking** | 依照电子订舱信息（accordance = 一致） |
| 定语 | **submitted via Magic Hand or Lindo Web** | 通过 Magic Hand/Lindo Web 提交的 |
